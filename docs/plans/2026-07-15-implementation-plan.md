# Thrive Through Cancer Implementation Plan

Date: 15/07/2026

## Build Sequence

1. Establish the static project structure, metadata and asset pipeline.
2. Build the semantic page structure and conversion hierarchy.
3. Apply the Quiet Vitality design system and responsive layouts.
4. Add mobile navigation, reveal behaviour and booking validation.
5. Add search metadata, a sitemap, robots instructions and structured data.
6. Run local markup and script checks.
7. Test desktop, tablet and mobile layouts in a real browser.
8. Inspect screenshots and correct visual defects.
9. Commit the complete build to a dedicated branch and push it to GitHub.

## Integration Follow Up

The following inputs are required before live payment and scheduling can be activated:

* Public practice email address and telephone number.
* Booking calendar provider and availability rules.
* PayFast merchant configuration and notification URL.
* EFT banking instructions and payment reference format.
* Privacy policy, terms and cancellation policy.
* Certification logos and permission to display them.
* Final approval of medical statistics and source attribution.
