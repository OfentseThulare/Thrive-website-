# Local font assets

These fonts are bundled locally so `next/font/local` can optimise and self host them without a build time network request.

## Alegreya Sans

Used for body copy and interface text at weights 400, 500 and 700.

Source: `google/fonts`, directory `ofl/alegreyasans`, retrieved 15/07/2026.

Files and official Git blob identifiers:

* `AlegreyaSans-Regular.ttf`: `2c9b0c50cd08e872a68d3b11587a40d59efc4fb9`
* `AlegreyaSans-Medium.ttf`: `25efd0dee46c4b5f125d970171c58cdc613635e9`
* `AlegreyaSans-Bold.ttf`: `5eb6c87008e255bb58a0488fed4641420d97ba1d`

The licence and upstream Google Fonts metadata are preserved in `licenses/AlegreyaSans-OFL.txt` and `licenses/AlegreyaSans-METADATA.pb`.

## Cormorant Garamond

Used as the editorial display face through its weight range from 300 to 700.

Source: `google/fonts`, directory `ofl/cormorantgaramond`, retrieved 15/07/2026.

File and official Git blob identifier:

* `CormorantGaramond-Variable.ttf`: `d992a83ce525c330fad3a19087746bcb2dc038ee`

The licence and upstream Google Fonts metadata are preserved in `licenses/CormorantGaramond-OFL.txt` and `licenses/CormorantGaramond-METADATA.pb`.
